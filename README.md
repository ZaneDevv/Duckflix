# Duckflix

**Duckflix** is a movie-discovery web application built with **Vue.js**. It allows users to search for movies and browse results through a clean, simple, and visually appealing interface.

Movie information is retrieved from an external API, providing movie titles and posters.

## ✨ Features

- 🔍 **Movie Search** — Search for movies by title or keyword.
- 🎬 **Movie Posters** — Display movie posters in a grid layout.
- 🌐 **API Integration** — Retrieve movie data from an external API.
- ⚡ **Fast Performance** — Powered by Vue and Vite.
- 🎨 **Clean Interface** — Simple design focused on browsing movies.

## 🚀 Getting Started

Follow these steps to run Duckflix locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ZaneDevv/duckflix.git
```

**2. Navigate to the project directory**

```bash
cd duckflix
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure the API**

If your movie API requires an API key, configure the necessary environment variables according to your application's implementation.

For Vite applications, client-side environment variables commonly use the `VITE_` prefix.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

Visit the URL displayed in your terminal, usually:

```text
http://localhost:5173
```

*These commands assume the standard Vite project scripts.*

## 📖 How to Use

1. Open Duckflix in your browser.
2. Locate the search bar at the top of the page.
3. Enter a movie title or keyword.
4. Browse the matching movies displayed in the results grid.
5. Search again to discover other movies.

## 📦 Production Build

To generate an optimized production build, run:

```bash
npm run build
```

The generated files are normally stored in the `dist` directory.

To preview the production build locally:

```bash
npm run preview
```
